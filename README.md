# 1º DAW - Códigos

Repositorio con los ejercicios y tareas que hice en **1º DAW** (curso 2025-2026) en el IES Tetuán de las Victorias.

Casi todo es de la asignatura de **Programación** en **Java**, y hay uno de **Entornos de Desarrollo** (pruebas con JUnit). Cada carpeta es un proyecto de **Eclipse**.

## Proyectos

| Carpeta | Tema | Qué hay |
|---|---|---|
| [EjercicioExcepciones](EjercicioExcepciones) | Excepciones | Calculadora con control de errores, excepciones propias, pescadería con números de turno... |
| [TareaObligatoria](TareaObligatoria) | Excepciones | Programa que detecta palabras prohibidas con la excepción `BurradasNOException` |
| [EjeColeccionesII](EjeColeccionesII) | Colecciones | Ejercicios con `ArrayList`, `TreeSet` y `HashMap` (carrera de coches, biblioteca, diccionario, Eliza...) |
| [TareaObligatoriaCrud](TareaObligatoriaCrud) | Colecciones | Gestión de un almacén (CRUD) hecho con `ArrayList` y con `HashMap` |
| [Ficheros-TareaDeClase-](Ficheros-TareaDeClase-) | Ficheros | Leer, escribir, copiar y ordenar ficheros de texto, contar líneas de un directorio |
| [TareaObligatoriaBuscarPalabras](TareaObligatoriaBuscarPalabras) | Ficheros | Comando que busca una palabra en un fichero de texto |
| [EntornosDesarollo](EntornosDesarollo) | Entornos de Desarrollo | Clase `Reloj` con sus pruebas unitarias en JUnit |

## Cómo abrirlos
1. En Eclipse: `File > Import > Existing Projects into Workspace`.
2. Seleccionar la carpeta del proyecto.
3. Ejecutar la clase que tiene el `main` (`Run As > Java Application`).

Cada carpeta tiene su propio README explicando los ejercicios.
