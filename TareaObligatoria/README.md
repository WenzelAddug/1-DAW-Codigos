# Tarea Obligatoria - Excepciones (BurradasNO)

Programa que lee mensajes por teclado y comprueba si tienen palabras prohibidas.

- `Test.java` -> pide mensajes hasta que se escribe `.`. Si el mensaje está bien muestra `OK`.
- `BurradasNOException.java` -> excepción propia que se lanza cuando el mensaje tiene una palabra prohibida, y muestra cuál es.
