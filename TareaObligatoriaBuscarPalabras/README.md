# Tarea Obligatoria - Buscar Palabras

Comando en Java que busca una palabra dentro de un fichero de texto. El proyecto de Eclipse está en `TareaObligatoriaBuscaPalabra/`.

## Uso
```
java Palabra <palabra> <fichero>
```
- `args[0]` -> la palabra a buscar
- `args[1]` -> el nombre del fichero

## Salida
- Por cada línea donde sale la palabra: el número de línea y su contenido.
- Al final: el total de líneas donde aparece.

`datos.txt` es el fichero de prueba.
