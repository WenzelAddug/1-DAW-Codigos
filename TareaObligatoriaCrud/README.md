# Tarea Obligatoria - CRUD Almacén

Gestión de los productos de un almacén con un menú por consola. Está hecho de dos formas para comparar las colecciones. El proyecto de Eclipse está en `TareaObligatoriaCrud/`.

- `MiAlmacenArrayList.java` -> versión con `ArrayList`
- `MiAlmacenHashMap.java` -> versión con `HashMap`
- `Producto.java` -> clase con nombre, stock, stock mínimo y precio

## Menú
1. Nuevo producto
2. Consulta producto
3. Borrar producto
4. Modificar precio
5. Compra de productos
6. Venta de productos
7. Listado completo de productos
8. Listado de productos con stock inferior al mínimo
9. Terminar
