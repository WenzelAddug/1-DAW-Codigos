# Ejercicios Colecciones II

Ejercicios de colecciones en Java. Están separados en dos paquetes: `ArrayList` y `HashMap`.

## ArrayList
| Ejercicio | Qué hace |
|---|---|
| `Eje01` | Carrera de coches: un `ArrayList` de objetos `Coche` que arrancan, aceleran, frenan y recorren distancia. Al final se ordena la clasificación |
| `Eje02` | Biblioteca con listas de libros disponibles y prestados (clases `Libro` y `Genero`) |
| `Eje03` | Lista de números aleatorios: mostrar, sumar, borrar los pares, cambiar los múltiplos de 3 por 0 e insertar 555 |
| `Eje04` | Lista de números aleatorios ordenada y pasada a un `TreeSet` para quitar los repetidos |

## HashMap
| Ejercicio | Qué hace |
|---|---|
| `Eje01` | La biblioteca otra vez pero con `HashMap` (prestar libros) |
| `Ejercicio02` | Login con un mapa usuario -> contraseña |
| `Ejercicio03` | Diccionario español-inglés: pregunta palabras y cuenta aciertos y fallos |
| `Eliza` | Mini chatbot que responde según las palabras que escribes (con mejora para los insultos) |
